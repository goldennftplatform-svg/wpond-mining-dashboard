## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure API Key
Edit `extract-complete-data.js` and replace `YOUR_API_KEY_HERE` with your Helius API key.

### 3. Extract Complete Data
```bash
npm run extract
```

### 4. Generate Advanced Insights
```bash
npm run insights
```

### 5. Launch Dashboard
```bash
npm run dashboard
```
